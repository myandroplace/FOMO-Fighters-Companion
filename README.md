# FOMO Fighters Companion ⚔️🏰

Android-приложение на **Jetpack Compose** и **Material 3** для игроков [FOMO Fighters](https://play.fomofighters.xyz):
- 🏰 **Аванпосты (История осад)**: отслеживание завершенных осад (Форты, Донжоны, Оплоты, Цитадели), участвующих кланов, очков влияния и наград участников.
- 📊 **Экспорт в Google Таблицы**: быстрая выгрузка данных в Google Sheets (TSV для моментальной вставки через `Ctrl+V` и вебхук через Google Apps Script).
- ⚔️ **Аналитика личных рейдов**: подсчет добычи ресурсов (еда 🌾, дерево 🪵, камень 🪨, алмазы 💎), учет цены потерь армии, чистой прибыли и ROI.
- 🧮 **Тактический калькулятор**: расчет рекомендуемой силы атаки для 3★ победы над лагерями скелетов и гоблинов, затрат на переобучение павших воинов.
- 🔄 **Интеграция с API игры**: поддержка прямого запроса к API, парсинга cURL-команд из DevTools и импорта «сырого» JSON.

---

## 📱 Скриншоты и возможности

1. **История осад аванпостов**:
   - Точное воссоздание интерфейса игры: дата, название, тип специализации (*Логистика*, *Боевые действия*, *Экономический*).
   - Клановое противостояние: уровни кланов, визуальная шкала очков и кубок победителя 🏆.
   - Раскрывающийся список участвующих кланов (поддержка 2, 3 и более кланов).
   - Окно «Влияние и награды участников» с детализацией по рангам, очкам влияния и добыче.

2. **Интеграция с Google Sheets**:
   - 📋 Копирование сводки осад в формате TSV (вставляется в ячейку A1 и раскладывается по столбцам).
   - 📋 Копирование таблицы участников и наград.
   - 🚀 Авто-выгрузка через Webhook Google Apps Script с готовым шаблоном скрипта.
   - ↗️ Прямой переход в Google Таблицу по ссылке.

---

## 🛠️ Стек технологий

- **Язык**: Kotlin
- **UI**: Jetpack Compose, Material 3
- **Архитектура**: MVVM (Model-View-ViewModel), StateFlow, Coroutines
- **Сеть**: OkHttp 4
- **Сборка**: Gradle (Kotlin DSL), Android Gradle Plugin

## 🚀 Сборка проекта

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/myandroplace/FOMO-Fighters-Companion.git
   ```
2. Откройте проект в **Android Studio**.
3. Запустите сборку:
   ```bash
   ./gradlew assembleDebug
   ```
